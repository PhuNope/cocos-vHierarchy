# cocos-vHierarchy

Cocos Creator 3.8.2+ Hierarchy customization extension inspired by Unity vHierarchy.

**Version: 0.1.0 (development).** Do not create Git tags or GitHub Releases until the project owner explicitly says **chốt**.

Initial TypeScript source and compact installation package were delivered as test ZIP attachments in the accompanying ChatGPT conversation. The ZIP packages are not GitHub Releases. Runtime testing in the actual Cocos Editor is still required.

Features under development: hierarchy guides, striping, palette, recursive node icons/colors, component minimap, bookmarks, toolbar, and active-state control. The extension must not patch `app.asar`.

Next steps: review the initial test build in Cocos Creator 3.8.8, incorporate test feedback, and sync the complete TypeScript source tree into this repository.

# vHierarchy

Hierarchy customization for Cocos Creator 3.8.2+.

## Main Features

- **Node colors:** Nine-color palette, color inheritance for descendants, gradient backgrounds, adjustable saturation and brightness, and color-aware selected-row highlighting.
- **Node icons:** Custom icons displayed in the Hierarchy, independent icon tint, recursive icon inheritance, and replacement of the native Prefab icon in its original position.
- **Icon library:** 36 bundled offline SVG icons, import of project-local PNG/WebP/SVG icons, searchable icon picker, and Google Material Symbols catalog with thousands of searchable icons.
- **Prefab appearance:** Preserve colors and icons across Prefab editing, Hierarchy refreshes, and additional Prefab instances while retaining Cocos' native Prefab text colors.
- **Hierarchy navigation:** Parent-child guide lines with click-to-collapse, keyboard navigation, bookmarks, navigation toolbar, and optional Scene Selector.
- **Node controls:** Hover-only Active checkbox, Lock control, Layer labels, and compact Hierarchy layout options.
- **Visual preferences:** Zebra striping, minimal mode, quick visibility toggles, and an integrated Settings/Palette menu.
- **Project-level persistence:** Save Hierarchy appearance, bookmarks, imported icons, and preferences per project without changing Scene or Prefab runtime assets.
